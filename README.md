# Garagem Inteligente - Lógica de Programação

**Atividade em grupo - 40 minutos**

## Missão

Uma loja de veículos precisa organizar uma pequena garagem virtual. Vocês vão completar um programa orientado a objetos que registra e apresenta informações de **dois carros**.

A atividade foi elaborada com base na Aula 11: **classe, objeto, atributo e método**, com um exemplo em Python e outro em Java.

**Escolham UMA linguagem como entrega obrigatória.** A outra pode ser explorada como atividade bônus.

## Como fazer

1. Entrem com uma conta GitHub e cliquem em **Fork**, no canto superior do repositório original.
2. Criem o fork na conta de uma pessoa do grupo. Essa pessoa será responsável pelos commits.
3. Abram o arquivo `python/carro.py` **ou** `java/Main.java`, conforme a escolha do grupo.
4. Cliquem no ícone de **lápis** para editar o arquivo pelo navegador.
5. Completem os TODOs: `exibirInfo()`, dois objetos `Carro` e duas chamadas do método.
6. Cliquem em **Commit changes...** e confirmem a alteração no **fork**, não no repositório do professor.
7. Copiem o código completo para um compilador online e cliquem em **Run** para testar.
8. Abram `REGISTRO_EQUIPE.md`, preencham e façam outro commit.
9. Enviem ao professor **a URL do fork** pelo canal de entrega indicado em aula.

> Não é necessário instalar Python, Java, Git nem usar terminal.

## O que precisa funcionar?

- Uma classe chamada `Carro`.
- Três atributos: `marca`, `modelo`, `ano`.
- Um método chamado `exibirInfo()` que apresenta os três atributos.
- Dois objetos com valores diferentes.
- Duas chamadas ao método e duas linhas de informações na saída.
- Um fork com commits e o arquivo `REGISTRO_EQUIPE.md` preenchido.

**Formato esperado de saída, usando dados fictícios:**

```text
Marca: Fiat | Modelo: Argo | Ano: 2020
Marca: Toyota | Modelo: Corolla | Ano: 2024
```

Vocês podem escolher outros veículos. Não precisa sair exatamente igual, mas **as três informações de cada carro precisam aparecer**.

## Organização dos 40 minutos

| Tempo | Etapa |
| --- | --- |
| 0-6 min | Formar equipe, escolher linguagem e criar fork |
| 6-16 min | Completar o método `exibirInfo()` |
| 16-25 min | Criar dois objetos e chamar o método |
| 25-33 min | Executar online, verificar e corrigir |
| 33-38 min | Registrar equipe e salvar commits |
| 38-40 min | Enviar o link do fork |

## Bônus, só se sobrar tempo

Criem um terceiro carro **ou** adicionem à classe o método `buzinar()`, que imprime `Bip bip!`. Não é obrigatório.

## Conceitos que devem explicar

- **Classe:** o modelo `Carro`.
- **Objetos:** os carros individuais criados a partir da classe.
- **Atributos:** marca, modelo e ano.
- **Método:** `exibirInfo()`, que mostra as características de um objeto.

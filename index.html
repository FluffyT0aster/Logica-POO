01 / O PROBLEMA

Uma garagem, dois carros e uma classe.

Vocês receberam parte do programa pronta. Agora precisam completar os trechos marcados com TODO.

CENÁRIO

Uma revendedora deseja mostrar os veículos cadastrados. Cada veículo tem marca, modelo e ano. Em vez de repetir as mesmas instruções, a equipe vai criar um modelo chamado Carro.

O que seu grupo precisa entregar?

01
Classe Carro

Usar uma classe como molde para todos os carros.

02
Três atributos

Marca, modelo e ano de cada carro.

03
Método exibirInfo()

Mostrar as informações do carro na tela.

04
Dois objetos diferentes

Criar dois carros e chamar o método em cada um.

05
Registro no GitHub

Salvar as alterações no fork e enviar o link.

💡

Não precisam fazer tudo do zero. A classe e seus atributos já estão no projeto. Foquem no método, nos dois objetos e no funcionamento do código.

02 / GITHUB NA PRÁTICA

Do repositório do professor ao fork da equipe.

Todo o processo pode ser feito pelo navegador. Escolham um integrante para salvar as alterações no GitHub.

  1. 01

    Acessem o repositório original

    Cliquem no link enviado pelo professor. Confirmem que estão logados no GitHub.

  2. 02

    Façam o fork

    No canto superior direito, cliquem em Fork, depois em Create fork. Agora vocês têm uma cópia na conta de um integrante.

    Fork = criar uma cópia própria para trabalhar sem alterar o projeto original.
  3. 03

    Escolham a linguagem

    Para Python, abram python/carro.py. Para Java, abram java/Main.java. Uma linguagem basta.

  4. 04

    Editem os TODOs

    Clique no arquivo e depois no ícone de lápis. Completem o método, criem dois carros e chamem exibirInfo().

  5. 05

    Salvem um commit

    Clique em Commit changes.... Use a mensagem Conclui desafio da garagem e confirme no seu fork.

    Commit = registro de uma alteração no histórico do projeto.
  6. 06

    Testem e registrem a equipe

    Copiem o código completo para o compilador online, executem, corrijam se necessário e atualizem REGISTRO_EQUIPE.md em outro commit.

  7. 07

    Enviem o link

    Copiem o endereço do fork da equipe e enviem no canal indicado pelo professor. Não enviem o link do projeto original.

Dicas sem entregar a resposta

Em Python ela começa com class Carro:. Em Java, com class Carro { ... }. Pense na classe como um molde.

Em Python, a ideia é variavel = Carro("Marca", "Modelo", 2020). Em Java, Carro variavel = new Carro("Marca", "Modelo", 2020);. Vocês precisam criar dois.

Use o nome do objeto seguido de ponto e método, como carro1.exibirInfo() em Python ou carro1.exibirInfo(); em Java.

Confiram a mensagem do compilador, a indentação no Python, os pontos e vírgulas no Java e se usaram o nome do método exatamente como exibirInfo. Se tiverem dúvidas, peçam ajuda ao professor.
